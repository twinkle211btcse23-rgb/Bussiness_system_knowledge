# Theory: Key Concepts

## Core Concepts

### 1. **Just-in-Time (JIT) Inventory**
A methodology to reduce waste by receiving goods only as they are needed in the production process.

### 2. **Kanban System**
A visual workflow management tool that helps teams visualize work, limit work-in-progress, and maximize efficiency.

### 3. **Supply Chain Optimization**
The process of improving the efficiency and effectiveness of a supply chain to reduce costs and improve delivery times.

### 4. **Data Pipeline**
A system for moving data from one system to another, often involving transformation and processing steps.

### 5. **API (Application Programming Interface)**
A set of protocols and tools for building software applications that allow different systems to communicate.

## Glossary

| Term               | Definition                                                                 |
|--------------------|----------------------------------------------------------------------------|
| **Lead Time**      | The time taken from placing an order to receiving the goods.              |
| **Bottleneck**     | A point in a process that limits overall throughput.                       |
| **Throughput**     | The amount of work completed in a given time period.                      |
| **Scalability**    | The ability of a system to handle increased workload without performance degradation. |
